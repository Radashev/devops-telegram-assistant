# DevOps Telegram Assistant

A clean Telegram bot project built with **Python 3.11, Aiogram and Poetry**.

This repository is focused on building a **clean DevOps-style project from scratch** with:

- proper Git branching strategy
- environment-based configuration
- Poetry dependency management
- Docker containerization
- future CI/CD integration
- deployment-ready structure

---

## Project Goals

This project is created to practice and demonstrate:

- clean project architecture
- reproducible setup
- working with Git branches (`main`, `develop`, `feature/*`)
- local bot запуск
- preparation for Docker and cloud deployment

---

## Current Status

Implemented:

- clean Git repository
- `main`, `develop`, `feature/readme` branches
- Python 3.11.5 via Poetry
- local `.venv` inside the project
